# Prompt inicial para Antigravity

Trabaja sobre este repositorio para construir la primera versión de una intranet colaborativa de investigación, deliberación y generación documental relativa a un proyecto de federalización de Bolivia.

Antes de actuar, lee completamente `CANON.md`, `AGENTS.md`, `docs/00_ACTA_FUNDACIONAL.md`, `docs/01_PRD.md`, `docs/03_ROLES_Y_PERMISOS.md`, `docs/06_ARQUITECTURA_TECNICA.md`, `docs/08_SEGURIDAD_PRIVACIDAD.md` y `docs/12_ROADMAP.md`.

Tu primera misión es ejecutar únicamente la Fase 0:

1. Auditar los documentos canónicos y listar contradicciones, huecos y decisiones pendientes.
2. Proponer `ADR-0001` para el stack y el monolito modular, incluyendo alternativas y reversión.
3. Definir el mapa de pantallas y los flujos críticos del MVP.
4. Producir un modelo entidad-relación inicial coherente con `docs/07_MODELO_DATOS.md`.
5. Crear un threat model inicial y una matriz de autorización por recurso/acción.
6. Preparar el backlog de Fase 1 con historias, dependencias y criterios de aceptación.

Restricciones:

- No implementes todavía funcionalidades productivas ni despliegues.
- No inventes posiciones políticas, normativa, datos, fuentes o aprobaciones.
- Marca cada supuesto y decisión pendiente.
- Separa claramente contenido institucional de decisiones de software.
- No reduzcas la seguridad a controles de interfaz.
- Toda recomendación importante debe quedar en un ADR o registro de decisión.

Entrega final esperada:

- `docs/audits/PHASE_0_GAP_ANALYSIS.md`
- `docs/adr/ADR-0001-architecture.md`
- `docs/product/SCREEN_AND_FLOW_MAP.md`
- `docs/architecture/ERD.md`
- `docs/security/THREAT_MODEL.md`
- `docs/security/AUTHORIZATION_MATRIX.md`
- `docs/backlog/PHASE_1_BACKLOG.md`
- actualización de `docs/13_REGISTRO_DECISIONES.md` y `CHANGELOG.md`

No marques la Fase 0 como completada: presenta los documentos para ratificación humana y enumera las decisiones bloqueantes.
