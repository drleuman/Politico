# Metodología de evidencia

## Objetivo

Evitar que una conclusión, cifra o comparación pierda su procedencia, contexto o grado de incertidumbre.

## Ficha de afirmación

Cada afirmación crítica debe registrar:

- Texto exacto y alcance.
- Tipo: hecho, interpretación, proyección o recomendación.
- Fuente y pasaje/localización.
- Periodo y territorio.
- Método de obtención/cálculo.
- Calidad y limitaciones.
- Responsable de verificación y fecha.
- Evidencia contradictoria o alternativa.

## Escala de calidad propuesta

| Nivel | Criterio resumido |
|---|---|
| A | Fuente primaria, método transparente, actual y directamente aplicable |
| B | Fuente sólida con limitaciones menores o aplicación indirecta |
| C | Fuente secundaria o datos incompletos; útil como orientación |
| D | No verificada, opinativa o insuficiente; no apta para sustentar una decisión sola |

## Reglas para datos

- Nunca mostrar una cifra sin unidad, periodo, cobertura y fuente.
- Distinguir valores nominales/reales, stock/flujo, observados/proyectados.
- Guardar el dataset o una referencia reproducible, su licencia y fecha de descarga.
- Documentar transformaciones, denominadores, redondeos y datos ausentes.
- Los escenarios deben declarar supuestos y sensibilidad.

## Comparaciones internacionales

Registrar por qué un caso es comparable, qué diferencias institucionales limitan la analogía y qué aspectos no se transfieren. Evitar rankings o ejemplos seleccionados sin criterio previo.

## Revisión

La revisión técnica valida método y trazabilidad; la jurídica valida interpretación normativa; la política decide la posición. Ninguna sustituye a las demás.
